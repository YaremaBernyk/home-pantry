# Home Pantry

Навчальний Flutter-застосунок для лабораторної №3 з дисципліни «Кросплатформене програмування». Поточний етап — desktop-інтерфейс за макетами лабораторної №2, без серверної бізнес-логіки.

## Екрани

Вхід, реєстрація, відновлення пароля, Dashboard зі статистикою, інвентар, профіль зі зміною пароля та діалог додавання продукту. Вхід відкриває домашню сторінку. Введене ім’я відображається на Dashboard і в профілі. Товари можна додавати, видаляти та змінювати їхню кількість; пошук, категорії та статистика оновлюються зі спільного списку. Дані зберігаються лише в пам’яті до виходу або перезапуску. Листи не надсилаються, справжня авторизація і зміна паролів не підключені.

## Запуск

Із кореня проєкту з налаштованим Flutter у PATH:

```powershell
flutter pub get
flutter run -d chrome
```

## Перевірка

```powershell
dart format lib test
flutter analyze lib test
flutter test
flutter build web --release
```

У Windows ці кроки можна виконати одним файлом:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Check-Lab3.ps1
```

Скрипт використовує інсталяцію `C:\Users\Yarema\flutter`. На іншому комп’ютері вказати `-FlutterSdk 'шлях до SDK'`. Результати записуються в `verification/`; під час першого запуску можуть завантажуватися залежності та компоненти Flutter. Збірка знаходиться в `build/web/`.

## Структура коду

```text
lib/
  main.dart
  core/widgets/pantry_widgets.dart
  screens/auth_screen.dart
  screens/home_screen.dart
test/
  widget_test.dart
scripts/
  Check-Lab3.ps1
```

Правила роботи — `AGENTS.md`; специфікація планів — `PLANS.md`; поточний план виконання — `plans/lab3-desktop.md`.

## Стан перевірки

Перевірка 05.10.2026 у PowerShell користувача підтверджена журналами: форматування виконано, аналіз без помилок, усі вісім віджетних тестів пройшли, release-вебзбірку створено у `build/web/`. Тести охоплюють навігацію, відображення введеного імені, додавання, зміну кількості та видалення продуктів, перевірку форми, скасування й очищення сесії після виходу. Скриншоти запущеної вебверсії підготовлено для звіту лабораторної №3.

Поточний інтерфейс розрахований на desktop-вікно 1440 × 1025. Реалізація адаптивного інтерфейсу у Flutter є наступним етапом. Мобільні та планшетні макети у Figma поки потребують завершення перевірки.
